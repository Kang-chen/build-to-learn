# 阶段文档 3 · 通关（每个阶段跑通后的验收仪式）

> **本文档每个阶段走一遍**，不是只在项目结尾。完成判据：通关仪式五步全走完。下一步：回 `2-施工.md` 开下一阶段；最后一个阶段通关 = 项目收口（见文末）。
> 轻验收（施工中随口的那种）细则在 `2-施工.md` 第六节，本文档只管通关级验收。

## 理念：本阶段在学什么

通关是**验收维度的主场 + 把认知钉进长期记忆的时刻**。验收练的是「AI 说做完了，我怎么知道真做完了」；钉记忆靠的是主动提取——考出来的才是自己的，读笔记不算。

## 策略

1. **真机对照防纸上谈图**：部件图是 AI 画的，图错则后面全对着错模型通过；真机现象是唯一的外部裁判。
2. **迁移四问照真懂**：没教过的新需求最照出认知模型的成色。
3. **间隔提取**：回头题 + 续学图问，把早前阶段的认知隔着时间再拉出来一次——接替被废除的小考的留存职能。
4. **滚动刷新让规划活着**：通关是阶梯的唯一强制重看点，不刷新它就会退化成死表。

## 大考配方（v2.6 单题制 · 2026-07-30 用户拍板「每关一道，不要太多」）

> Quick 不增加题量。正例、错误例、升级例和迁移例是开发者评估 skill 的回归套件，不是四道用户考试。规则类修改可以把“请设计一组最小正反例并说明为何能验收”作为下面唯一一道正题。

1. **第 0 题 · 真机对照（不拦路，v2.7）**：整阶段**首次联跑之前**，一句「心里押一下会跑成啥样」——**不等回答**。按统一节奏入口决定由谁运行：Quick 的自动测试由 AI 连续完成并展示证据；只有亲手操作会产生不可替代体验时才交给用户。跑完拿现象回照讲；他真开口说了预测就认真对照，没说就只回照现象，不让他事后补。
2. **正题只有 1 道**——这是**全流程唯一需要用户开口应答的检验**（v2.7）。AI 挑**当时最值**的题型出（判据：最大虚点 ∪ 本阶段要害），四个小问以内：
   - 题型池：重建本阶段数据流（不看笔记）／指图故障定位（描述坏现象让他说坏在哪段）／迁移四问（没教过的新需求：动哪个部件、照哪个形状、踩哪个坑、怎么验）／回头题（早前阶段虚点）。
   - **迁移四问优先**——一道就覆盖判断、定位、坑、验收四个维度。
   - 没考到的维度和虚点**不加题**：记进学习地图「认知模型待加固」，靠下阶段的真实施工和下次通关消化。
3. 立项预测若落在本阶段，回照一句（不算题）。

强调「说思路就行，不求漂亮，答错正好暴露要回炉的地方」。出题前先报一句考法，用户认可再开考；喊停就停。
> 沿革：原 4~6 道配方。2026-07-30 S3 大考实测：4 道到第 3 道用户弃答「都不知道」并点名「太多了，每个 MVP 出一道就行」。用户一个阶段的问答总预算 ≈ 开场图问 1 道＋通关 1 道，按这个预算排。

## 批改规矩

- **每道题先重复原题文字（一行），再写点评**（2026-07-12 用户点名）——用户答完到看回复有时间差，题文在上方，不用翻回去对照。
- **批改给"认知模型地图"**：逐题点评后，画一张「结实 ✅ / 偏虚 🔶」清单，虚点按三问归类（判断虚 / 定位虚 / 验收虚），并指出**虚的那块对应接下来哪个阶段**——让测验接回建造主线，不是为考而考。

## 🔒 通关硬关卡（焊死，别只当原则）

一旦你要说出「S? 通关 / 这一阶段搞定 / 闭环合上」这类**宣布通关的话**，顺序锁死、不许跳：

**① 宣布通关 → ② 立刻发起大考（上面配方）→ ③ 批改给认知地图 → ④ 落盘四件（动作前先 Read `4-笔记.md`）：**
- **成文化学习记录**：要点焊成复盘文、部件图刷终版放开场；
- **登记能力块**进 `_能力库.md`，含**翻案检查**：本阶段有没有推翻库里旧卡的边界？有 → 同轮改卡；
- **刷学习地图**：阶梯翻 ✅、「现在在哪」推进到下一阶段、虚点进「认知模型待加固」；
- **滚动刷新阶梯**：远阶段要不要增删改写？下一阶段还成立吗？下一阶段此刻从一行字升为切实——改了当场落。
**→ ⑤ 交付证据包 → ⑥ 才能做复盘、问下一步。**

**证据包不是追加考试**，由 AI 在最终报告里一次交付：本阶段采用的判断/原则；改动落在哪些文件或位置；自动测试、正反例或真机现象及其结果；仍存在的不确定性。不能只报“已经完成”，也不要求用户为机械证据逐项确认。

（为什么焊死：大考、成文化都曾被流水线末尾的"问下一步"挤掉，故绑死在固定步上。旧「子格/整级两档」随子格废除——每次通关都是整阶段通关，单档。）
唯一例外：用户明确说「别考了/别成文了，往下 / 先停」——尊重，但在「现在在哪」记一笔"S? 大考/成文欠着"，下次续上补。

## 续学图问（跨会话的记忆闸门 · **自答式，v2.7 用户拍板** · 本节是真源，地图接管协议里那步是指针）

续做项目、搭台之前，出一道图问：重建当前阶段的部件图，或指图定位一个故障。**题和答案同一条消息给**——题在上、答案紧跟在下，提示他先自己想一下再看答案；出完**不等回答**，同一条消息正常往下接（接续做流程）。他自比后的三种走向：没差 → 直接继续；有差、他开口问 → 先复习再走；他说**连骨架都没印象** → 超容量信号——这个阶段装多了，按「阶段四判据」（`1-立项.md` 画阶梯节；动阶梯前没读过就先 Read）当场拆成两个都能跑的阶段。
> 沿革：v2.6 及以前是抛题等答。2026-07-31 用户点名「问完直接给答案就行」「考验在少且关键的地方」——需应答的检验全流程只剩通关正题，图问的留存职能靠自比保底。

## 何时算学会（项目收口）

阶梯上每个阶段都过了大考、真的造出了能跑的成品，且用户对一个没教过的新需求能答**「学会」四问**（即大考配方第 4 题，全文见 SKILL 委托人坐标系）。到这步收口：点明他掌握了哪几块能力、`_能力库.md` 里攒下了什么、现在能自己往哪做。不必无限加东西。

> 翻案注记（2026-07-28）：旧「四力度验收」（轻验收/小考/大考/整级验收）并成两力度——小考的留存职能由回头题 + 续学图问接替，整级验收并进大考第 0 题。仪式密度过高，是废除子格的同案。
